세종 아트 페스타 행사안내 웹페이지
=================================

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 웹 브라우저에서 엽니다.

구성
- index.html: 행사 안내 메인 페이지와 팝업 마크업
- css/style.css: 색상, 레이아웃, 반응형 디자인
- js/main.js: 메뉴, 달력, 팝업, 사전등록 완료 기능
- assets/: 첨부 포스터에서 추출한 실제 이미지 파일

구현 기능
- 모바일 반응형 화면
- 사전등록 버튼 클릭 시 '사전등록 완료'와 닫기 버튼이 있는 팝업 표시
- 전체 일정 보기: 2018년 5월 달력과 날짜별 프로그램
- 전체 프로그램 보기: 달력형 날짜 안내와 가상 작가·작품 목록
- 주석으로 주요 HTML/CSS/JS 기능 설명

참고
이 웹페이지는 디자인 시안을 위한 데모입니다.
작가명, 작품명, 일부 일정 정보는 임의로 구성했습니다.
사전등록은 완료 안내만 표시하며 실제 신청 정보를 저장하거나 전송하지 않습니다.
